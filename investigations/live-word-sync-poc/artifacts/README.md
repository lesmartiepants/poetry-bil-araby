# Local evidence archive

`comparisons/` holds immutable reports, WebMs, MP4s, screenshots, PCM extracts,
and the run ledger. Keep these files on the investigation volume so the Runs
viewer can inspect them; do not add them to Git.

The current decision, limits, and resume path are in
[`../STATUS.md`](../STATUS.md); the broader method/voice screen is documented in
[`docs/TTS_WORD_SYNC_INVESTIGATION.md`](../../../docs/TTS_WORD_SYNC_INVESTIGATION.md).
Retained lab profiles are visible in the control rail; archived profiles remain in `poc.js` so
historical reports stay reproducible.
