# Local evidence archive

`comparisons/` holds immutable reports, WebMs, MP4s, screenshots, PCM extracts,
and the run ledger. Keep these files on the investigation volume so the Runs
viewer can inspect them; do not add them to Git.

The current portfolio decision and complete method/voice matrix are documented
in [`docs/TTS_WORD_SYNC_INVESTIGATION.md`](../../../docs/TTS_WORD_SYNC_INVESTIGATION.md)
on the Live-TTS PR. Retained lab profiles are visible in the control rail;
archived profiles remain in `poc.js` so historical reports stay reproducible.
