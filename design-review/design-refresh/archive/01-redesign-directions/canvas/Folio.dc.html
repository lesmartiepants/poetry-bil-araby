Direction 03 · The type purist

Folio

One type family with true Arabic and Latin, set like a finely printed book. Spacing does the emotional work. Everything else is apology.

Built from

The type purist: four typographic voices in four lines. Plus the missing learner feature: meter.

Principles
  • Markazi Text for everything, three sizes.
  • Hemistichs set as the classical stagger.
  • English as marginalia, never a peer.
  • Words, not icons, for navigation.
Flow
  1. Choose from the contents
  2. Read the poem as a page
  3. Reveal the meter
  4. Write in the margin
  5. Revisit your margins
  6. Search by root or meter
Audience: readers who already love the form. Trades discoverability for calm.
