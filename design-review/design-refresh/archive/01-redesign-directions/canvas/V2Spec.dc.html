Accessibility and build notes

  • Each line is its own element with lang="ar" dir="rtl" or lang="en"; screen readers switch voice per line.
  • Verse is real text, never an image, so it can be selected, zoomed and translated.
  • Words are buttons inside the line; arrow keys move between words, Enter opens the sheet.
  • Sheets trap focus, close on Escape, and return focus to the word.
  • Live regions: polite for loading and saves, assertive only for errors.
  • PWA: service worker caches texts on view; audio only when downloaded.

Content rules

  • Every poem carries a source edition and an editor-verified flag before it can publish.
  • Tashkeel and translation are reviewed together; person and number must agree.
  • AI text is always labelled, cites what it drew on, and can be reported.
  • Errors: what happened, then what to do. Buttons are verbs.
