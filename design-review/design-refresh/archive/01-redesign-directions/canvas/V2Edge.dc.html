NIGHT READER · EDGE STATES

The screens nobody mocks up

The v1 explorations skipped these. Each state says what happened, what still works, and the one next step.

State rules
  • First run sets default layers by self-reported level; changeable any time in Layers.
  • Loading uses a skeleton shaped like the real layout; the shimmer is off under Reduce Motion; a polite live region announces "Loading poem".
  • Offline degrades by feature: text works, audio says why it doesn't.
  • Errors name the cause and the fix, and never block reading.
  • Empty states teach the gesture that fills them.
  • No results is honest about the catalogue (rights), and offers a root search.
Still to design: reminder permission denied, account sync conflict, very long poems (lazy loading), right-to-left screen reader order audit.
